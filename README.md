# livingMargin

A web app where you upload a PDF and an AI agent generates interactive UI components in the right margin, paragraph-by-paragraph. No chat — just upload, scroll, click.

Built for a 2-hour Generative UI hackathon focused on A2UI patterns.

## Status

Spec phase. See [`docs/superpowers/specs/2026-05-09-livingmargin-design.md`](docs/superpowers/specs/2026-05-09-livingmargin-design.md) for the full design.

## Stack

- Forks the [Generative-UI-Global-Hackathon-Starter-Kit](https://github.com/jerelvelarde/Generative-UI-Global-Hackathon-Starter-Kit)
- Next.js 15 + CopilotKit + A2UI catalog
- LangChain Deep Agent (Python) + Gemini 3.1 Flash-Lite
- MCP-UI for an open-ended image card (Tier 2)
