# Mockups — style direction (not 1:1 with the spec)

These mockups were generated by a sibling research project ("Lectern") that explores the same problem space — generative UI overlays for PDF/web reading. They are uploaded here as **style and quality direction**, not as a literal redesign of livingMargin.

## What to take from these

- **Pattern: anchored sidenote with hairline leader-line** — every margin card is visually pinned to the source span it explains. See `04-sidecard-anchor-closeup.png` for the close-up.
- **Mood / quality bar: library-warm, editorial, scholarly** — Stripe Press meets a beautifully designed printed book. Not techy. Not SaaS-dashboard.
- **Component vocabulary worth copying:**
  - Anchored sidenote (slim card, accent left-rule, leader-line to span)
  - Definition popover (term + plain-language gloss)
  - Key-fact callout (big number + small label, e.g. "8.2× HR")
  - Animated micro-explainer card (paused-state still + chrome strip showing duration)
  - Diagram card with "AI-generated · approximate" badge
  - Equation card (rendered formula + plain-language gloss line)
- **Typography pairing**: editorial serif for the source pane (Source Serif Pro / Tiempos / Crimson Pro), geometric sans (Inter) for UI chrome.
- **Trust signals**: every card carries an anchor + claim + provenance footer ("Cited from p.4 ¶2 · verified verbatim", "Generated · approximate", "Rendered locally · 1.8s · cached"). Without all three, a card shouldn't appear.
- **Empty-state treatment**: see `06-empty-import.png`.

## What does NOT match livingMargin's spec

| | Lectern mockups (here) | livingMargin spec |
|---|---|---|
| Palette | Parchment `#F8F4EC` + sage/indigo/amber per domain | Zinc neutrals + per-component accent (blue/purple/green/amber/rose) |
| Layout | Split-pane 62/38, scroll-anchored cards in a rail | CSS grid `1fr 320px`, one row per paragraph |
| Domain modes | Medical / legal / academic auto-detected | General-purpose |
| Visuals | Nano Banana illustrations + Hyperframe/Remotion explainers | A2UI catalog (BioCard / Chart / Map / QuoteHighlight) + optional MCP-UI image card |

So: don't reskin to match these — they're a different product. **Use them for the quality bar, the anchored-sidenote pattern, the trust-signal placement, and the "default to no component" feel.**

## How these were made

- 7 parallel Codex CLI agents, each calling `gpt-image-2`
- A single shared style-reference sheet (`00-style-reference.png`) was generated first, then passed to every other agent as a multimodal input image to keep the visual language consistent
- High reasoning effort, ~2-4 min per image
